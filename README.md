# API Automation Testing

Proyecto de automatización de pruebas de API utilizando Postman y Newman.

## Descripción

Este proyecto contiene una colección de pruebas automatizadas para validar diferentes endpoints de una API REST.

Las pruebas fueron desarrolladas utilizando Postman y posteriormente ejecutadas mediante Newman desde PowerShell.
